# Governance Framework

## Decision rights

| Decision | Authority |
|---|---|
| Rename variable | Developer |
| Add parameter | Senior Developer |
| Remove parameter | Architecture Review Board |
| Remove entire abstraction layer | Executive Steering Committee |
| Use a one-line command instead | Prohibited without waiver |

## Exception process

Exceptions require:

1. written justification;
2. business impact statement;
3. rollback strategy;
4. identification of the person who originally asked for this;
5. a meeting scheduled at the least convenient common time.
