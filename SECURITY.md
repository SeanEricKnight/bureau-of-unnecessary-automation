# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 0.4.x | Yes |
| 0.3.x | Emotionally |
| 0.2.x | No record exists |
| 0.1.x | Vision only |

## Reporting a vulnerability

Please do not open a public issue containing credentials, secrets, private keys, production hostnames, or screenshots of somebody's desktop with Outlook open behind the error message.

For all other concerns, open an issue titled `SECURITY: something has become unexpectedly functional`.
